# NYC Taxi Ride Pooling — Ensemble Study

Dissertation notebook for **Advancing Shared Taxi Systems**: demand prediction and ride-pooling ensembles on NYC Yellow Taxi trip data.

**Author:** Vishal Sharma

## Notebook

- `NYC_TaxiRidePooling_AllEnsembles.ipynb` — main research notebook (14 models: baselines + ensembles)

## Setup

```bash
pip install -r requirements.txt
jupyter notebook NYC_TaxiRidePooling_AllEnsembles.ipynb
```

Requires a Kaggle API token (`kaggle.json`) for dataset download.

## Version history

Git commits reconstruct the notebook’s evolution from the original pickup-density baseline through the enhanced ride-pooling and full ensemble study versions.
